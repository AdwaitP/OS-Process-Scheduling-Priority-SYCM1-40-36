Priority Process Scheduling

Master one of the core Operating System CPU scheduling algorithms. Learn the difference between pre-emptive and non pre-emptive modes and simulate them instantly.

What is Priority Scheduling?

Priority scheduling is a non-proportional algorithm in which each process is assigned a priority. The CPU is allocated to the process with the highest priority. Equal-priority processes are scheduled in First-Come, First-Served (FCFS) order.

Convention used in this simulator: A lower number indicates a higher priority. For example, Priority 1 is higher than Priority 5.

1 Non Pre-emptive

Once the CPU has been allocated to a process, the process keeps the CPU until it releases it, either by terminating or by switching to the waiting state. Even if a newly arrived process has a higher priority, it must wait for the current process to finish.

2 Pre-emptive

If a newly arrived process has a higher priority than the currently running process, the CPU is preempted (taken away) from the current process and given to the new one. The preempted process is put back into the ready queue.

! Starvation & Aging

Starvation: Low-priority processes may never execute if high-priority processes keep arriving.
Aging (Solution): Gradually increasing the priority of processes that wait in the system for a long time.
